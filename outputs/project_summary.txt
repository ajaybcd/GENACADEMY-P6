Project purpose
This Week 6 project uses Microsoft Presidio to detect and replace selected personally identifiable information before text is forwarded to an LLM or a vector-ingestion receiver. The interactive Streamlit demonstration needs no API key. On the hosted app, the original input is processed on the Streamlit server, so use synthetic examples only.

How it works
The Analyzer finds entity types, character positions and confidence scores. Pattern recognizers detect structured values, while a spaCy model helps identify names and locations. The Anonymizer replaces detected spans with labels. The forwarding API accepts one text field, and only the sanitized result can reach its configured receivers. A sanitizer failure blocks forwarding.

Examples for every selected type
We ran one example each for a person, email address, phone number, credit card, US social security number, IP address, location, bank account IBAN, US passport and US driver license. All ten complete example values were removed. Nine examples included their expected entity type. The social security number fixture was replaced as a phone number, showing that removing a value and classifying it correctly are different checks. The passport example also redacted the country abbreviation as a location.

Clean text and disguised input
Challenge examples deliberately probe detection gaps. A full-width email and a private alias were not masked. An email using bracketed at and dot was partially masked, leaving address fragments visible. These are observed misses, not successful redactions. A clean request to summarize the refund policy stayed unchanged. These examples are separate from the main evaluation and are not an independent accuracy benchmark.

Measured evaluation
The main evaluation has twenty-eight synthetic cases. The twenty-four standard and negative cases contain twenty annotated PII values. Exact entity-and-span precision and recall are both ninety-five percent. No complete standard value remained, but two of four challenge values stayed visible. Both API forwarding routes passed tests with local HTTP receivers, and six isolated gateway contract tests passed. No live LLM or vector database was tested.

Next steps and limits
This is an English-language prototype. It does not guarantee that all PII will be found, prevent prompt injection or replace access controls. Production work includes authentication, rate limiting, secure downstream adapters and representative domain tests. The repository includes the app, code, notebook, evaluation evidence, workbook, presentation, summary document and computer-generated voiceover. No video is included.
